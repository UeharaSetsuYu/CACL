## Prerequisites

Before running this project, ensure you have the following installed:

Python  3.9.7 

torch==2.6.0+cu123

numpy==1.26.4

## Datasets 
NGs are small-shot datasets, which can be found in the [`./demo/data/`](./demo/data/) folder. Other large-scale datasets will be provided via a cloud drive link upon publication.

## Usage

Running by NGs:
```bash
python Run_model.py --datasets 1 --view_num 3  

```
